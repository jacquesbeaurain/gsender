# Controller Events Demo Plugin

Mirrored reference plugin for gSender C++/Qt and Wasm runtime.

## Capabilities
- Listens to `workspace` topic for real-time DRO coordinates (X, Y, Z, A).
- Listens to `controller` topic for machine active states (Idle, Run, Alarm, Jog).
- Demonstrates C Wasm topic dispatch and reactive QML UI rendering.
